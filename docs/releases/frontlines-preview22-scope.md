# Frontlines preview22 — two-sided portrait hair

The source hair and eyebrow meshes are authored as two-sided surfaces. The portrait shader now preserves that property and retains the engine's back-face lighting. Render-cache version4 regenerates existing portrait images without changing the saved appearance recipe.

The updater also defers its offer while the commander creator is open, including while appearance edits are unsaved.

This is a narrow material and editor-safety follow-up to preview21. The client renderer, portrait render-cache version, creator update deferral and release/package metadata are the only runtime changes; all creator fit and touch behaviour remains as accepted in21. There are no backend or gameplay-rule changes. Fresh creator/profile, fit, touch, all-ten-hairstyle front/profile/rear, thermal scheduling, pause and responsive checks accompany the complete game baseline from21. Exact native and browser observations are recorded separately.

A public packet is immutable after freezing. Preview21 remains preserved;22 gets its own browser path and APK.
