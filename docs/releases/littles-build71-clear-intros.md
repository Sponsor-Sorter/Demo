# Littles71 — clear farm-scene introductions

The shared game intro combined dark brown inherited instruction text with a dark brown translucent gradient. This made Garden Memory and other introductions hard to read over their farm artwork. Remove the gradient at both the base and theme layers and use warm white, bold text with a subtle dark letter shadow. The intro heading and instruction area stay directly over the full-screen scene. Actual buttons retain their normal surfaces.

The new Spot the Difference level label also uses plain lettering over the scene, with no coloured text panel. Existing gameplay, difficulty/hints, approved audio, saved records and completed-round allowance stay unchanged; public mechanics remains70. Content71 invalidates the stylesheet cache through the normal app content update. The no-coloured-intro-text-backing requirement is recorded in the local game guidance to prevent the same theme regression.

Verification uses the user's actual Garden Memory phone example, final combined browser styles and visual comparisons on phone/tablet sizes, regression checks and native introduction checks after deployment.
