# Build 41 — Forgiving wool cleaning

Completes Pip’s hands-on overhaul from build 40. Brushing now snaps a patch fully clean once 85% has been removed. This avoids nearly invisible residual dirt blocking progress for preschool children. Stationary touches and strokes away from the lamb still do not clean any wool. A regression check verifies that a natural stroke finishes an almost-clean patch.

The Pip runtime uses a new cache version so existing players receive this change. All four physical activities and the animated lamb remain as documented for build 40.
