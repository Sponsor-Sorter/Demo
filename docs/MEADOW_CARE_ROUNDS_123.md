# Farmer Jay's care rounds — build 123

Animal Family now includes a compact care-round entry inside the scrollable roster. It opens a plan for food, brushing and play across every owned farm. Each action applies the existing free care amount only to animals below 75% in that need. Very low needs may require multiple rounds. It never spends wheat treats, buys anything, or collects produce. The existing care-game shortcut chooses the lowest relevant need, preserving the map-qualified animal ID. A new ElevenLabs Farmer Jay narration explains the care round, plays on first opening, and can be replayed from the guide button.

The farm desk prioritises completed, unclaimed goals. Animal-family goals now open Animal Family; the comfort goal opens the care round. Rewards continue to use the saved journal's exact-once claim protection.

Focused checks cover duplicate animal IDs on different maps, two low-need rounds, no-op repeats, invalid actions, unchanged wheat, untouched produce timers and a single module-level save/render per batch.
