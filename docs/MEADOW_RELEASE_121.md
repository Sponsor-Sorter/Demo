# Build 121 — compact production
Production panels now cap at 800×580, with scrollable recipe/helper controls. Collect and queue-gem controls sit left of the asset. Queue bundles cost quantity + 1 gems (one: 2; three: 4; five: 6; eight: 9), up to eight extra slots per building. Server validates ownership, current purchased level, wallet and replay IDs. Insufficient gems opens the shop without making a pack purchase.

Littles build 6 removes painting Pause, adds PNG saving and confirmed Clear all, enlarges drawing tools on larger screens, removes green chrome, and retains local paired connections only during the open session. Android 0.2.1 includes the system PNG Save picker.
