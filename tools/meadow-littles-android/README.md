# Meadow Market Littles Android test app

Independent package com.meadowmarket.littles. Opens https://sponsorsorter.com/meadow-market-littles/. Same Capacitor and Android toolchain as Meadow Markets; separate saves and installation.

Run npm ci, npx cap sync android, then npm run android:debug. Web updates use the game install-update prompt. Native changes require a new APK. Testing purchases are not real billing.
