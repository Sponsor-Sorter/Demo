Frontlines optional map assets - revision 1

These unlisted files are staged for an upcoming, separately accepted map-library release. Their presence does not make maps available in build 25.

Each PCK contains only declared raw map data, PNG textures/thumbnails, meshes and attribution/license notices. Per-map credits describe source datasets, transformations and artistic reconstruction limits. The original master 8K authoring images are excluded.

See delivery-r1.json for pinned URLs/hashes and credits links; packs-r1-manifest.json is the original pack inventory.
