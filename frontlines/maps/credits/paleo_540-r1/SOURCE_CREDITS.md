# Cambrian - 540 Ma - source credits

Coastline and continental motion: Merdith et al. (2021), reconstructed with the GPlates Web Service at exactly 540 Ma. Dataset: https://doi.org/10.5281/zenodo.10346399 . The dataset record identifies the licence as Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/). Metadata receipts are retained in the authoring folder.

Muller, R. D. et al. (2019), A Global Plate Model Including Lithospheric Deformation Along Major Rifts and Orogens Since the Triassic. Tectonics. https://doi.org/10.1029/2018TC005462

Merdith, A. S. et al. (2021), Extending full-plate tectonic models into deep time: Linking the Neoproterozoic and the Phanerozoic. Earth-Science Reviews 214, 103477. https://doi.org/10.1016/j.earscirev.2020.103477

API geometry and reconstructed points: https://gws.gplates.org/ . Exact request URLs, source SHA256s, age and model appear in source/provenance.json and the manifests. The received geometry is archived, rather than relying on the service to remain unchanged. GPlates software is GPL v2; its software licence is distinct from these dataset licences.

Changes: projection to Natural Earth I; rasterisation; illustrative game territories/bonuses and sea routes; inferred artistic relief, vegetation, rivers and surface materials. These are reconstructed, stylised game boards, not measured surveys of ancient terrain. Fine landscape features are artistic inference. Broad reference methodology: Scotese & Wright (2018) PaleoDEMs, https://doi.org/10.5281/zenodo.5460860 ; that raster model's different reference frame was not silently mixed into the GPlates coastline.

User-supplied browser screenshots selected the era silhouettes and composition. The reference site is https://thepangeamap.com/ . Its Natural Earth I projection and rounding of display frames to 10 Ma were inspected; this pack uses the exact requested 540 Ma reconstruction. Browser screenshots and site code are not redistributed in the runtime pack.

Terrain painting: generated for Frontlines with the built-in ImageGen tool using the approved painted-world/menu artwork as style references. Original output and exact prompt are retained in source/. Native generated colour resolution is 1774 x 887. The 8192 x 4096 authoring composite combines registered/resampled painting with authored relief/material detail; it is not described as a native 8K AI painting. Desktop colour is 4096 x 2048; phone colour is 2048 x 1024. Fine relief/normal detail is a separate registered layer.

Frontlines runtime, approved UI, unit rigs, cards, dice, boat and water/parchment materials remain project assets. The project's MIT notice is included as PROJECT_LICENSE.txt. No UI, unit, troop count, text or faction ownership is baked into the base painting.
